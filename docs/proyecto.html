Águila Blanca Sacabollos

Sistema de gestión y control para el taller — reemplazando papel por un circuito único de ingreso, reparación y cobro.

📋 En planificación — Fase 1 de 6

🎯 De qué se trata

Águila Blanca hoy gestiona todo su circuito de reparación de bollos (PDR) en papel: agenda física, fichas sueltas y control manual de facturación. Este proyecto construye una web app propia — con infraestructura y base de datos separadas de cualquier otro negocio — para que dueño, recepción y taller trabajen sobre un único sistema, usable desde tablet en el taller y desde PC en la oficina.

Esta página muestra el estado actual del proyecto: contexto, investigación de dominio y roadmap ya definidos. La construcción de la aplicación todavía no arrancó — el próximo paso es la Fase 1 (Fundaciones).

🔁 El flujo del negocio

Canal Seguro

  1. Denuncia + número de siniestro
  2. Inspección, presupuesto y fotos
  3. Envío a la compañía por mail
  4. Compañía envía la orden de trabajo
  5. Turno → ingreso → reparación → firma
  6. Factura → cobro o reclamo a la compañía

Canal Particular

  1. Presupuesto y fotos
  2. Cliente acepta → turno
  3. Cliente no acepta → se guarda contacto
  4. Ingreso → reparación → firma
  5. Factura → cobro
