# Plan de Implementación — Fase 6: CRM y Gestión de Equipo

**Fecha:** 2026-09-10  
**Spec:** `docs/superpowers/specs/2026-09-10-fase-6-crm-design.md`  
**Rama:** `feat/phase6-crm` en worktree `.worktrees/phase6`

---

## Tareas Planificadas

### Task 1: Base de Datos y Migración `0007_crm_y_equipo.sql`
- Crear migración con tablas `clientes`, `aseguradoras`, `productores`.
- Políticas RLS:
  - `dueno` y `recepcion`: control total (CRUD).
  - `taller`: lectura en `clientes` y `aseguradoras`.
- Backfill inicial y semillas de aseguradoras históricas.
- Tests de migración en `src/features/casos/migration.test.ts`.

### Task 2: Tipos y Capa API de CRM
- Crear `src/features/crm/types.ts`.
- Crear `src/features/crm/api.ts` con funciones CRUD tipadas para clientes, aseguradoras y productores, además de cálculo de métricas de casos.
- Tests unitarios en `src/features/crm/api.test.ts`.

### Task 3: Pantalla Principal de CRM (`CRMPage.tsx`)
- Crear `src/features/crm/CRMPage.tsx` con navegación por tabs:
  - Tab 1: Clientes (búsqueda, historial de vehículos, enlace directo a WhatsApp y llamada).
  - Tab 2: Aseguradoras (listado, contacto de siniestros, casos activos).
  - Tab 3: Productores (directorio de asesores y casos derivados).
- Modales para agregar y editar clientes, aseguradoras y productores.
- Tests en `src/features/crm/CRMPage.test.tsx`.

### Task 4: Gestión de Equipo e Invitaciones (`InvitarPage.tsx`) y Rutas
- Crear `src/features/equipo/InvitarPage.tsx` en `/invitar`.
- Habilitar `/crm` y `/invitar` en `src/app/routes.ts` y en `src/app/AppRouter.tsx`.
- Tests en `src/features/equipo/InvitarPage.test.tsx`, `src/app/routes.test.ts` y `src/layout/AppShell.test.tsx`.

### Task 5: Verificación Integral, Migración Supabase y Rollout
- Ejecutar suite completa de tests (`npm test`).
- Verificar typecheck (`tsc -b`), lint (`oxlint`) y build de producción (`npm run build`).
- Aplicar migración 0007 a Supabase (`npx supabase db push --yes`).
- Merge a `main`, push a GitHub, actualización de `README.md` y verificación en Vercel.
