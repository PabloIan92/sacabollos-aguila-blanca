## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| canal Realtime → clientes suscriptos | El payload de `postgres_changes` respeta la misma RLS de `casos` que el select normal — un taller no recibe eventos de casos que no podría leer por API |
| lista en memoria del cliente → verdad de la base | El array local de cada home se actualiza por evento incremental; si un evento se pierde (reconexión), la lista puede quedar desactualizada hasta el próximo refetch manual |
